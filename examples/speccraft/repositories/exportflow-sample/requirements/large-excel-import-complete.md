# 超大 Excel 订单异步导入与导出闭环（真实模型 Smoke）

[actor] 订单运营人员发起导入并查看处理结果。
[flow] 上传超大 Excel 后创建异步导入任务，通过 SSE 展示进度，完成后进入既有订单查询与导出链路。
[data] 记录任务状态、总行数、成功行数、失败行数、文件引用和行级失败原因。
[permission] 只有订单运营角色可以发起并查看自己创建的导入任务。
[failure] 重复请求按幂等键返回同一任务；失败行记录原因并允许部分成功。
[compatibility] 不改变现有订单导出接口与数据口径。
[non-functional] 文件采用流式解析，单任务内存有明确上限，请求线程不等待完整处理。
[acceptance] 导入成功的订单可以查询，并能通过既有异步导出链路导出。
